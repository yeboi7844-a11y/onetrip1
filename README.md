# OneTrip beginner project\n\nA starter app using Next.js App Router, TypeScript, Tailwind CSS v4 and Zod. Demo records live in a TypeScript file (no database server required).\n\n## Run in VS Code\n1. Install Node.js 20.9 or newer.\n2. Extract ZIP and open this folder in VS Code.\n3. Open Terminal and run `npm install` then `npm run dev`.\n4. Visit http://localhost:3000. Stop with Ctrl+C.\n\n## Customize\n- Homepage: `app/page.tsx`\n- Styles/colors: `app/globals.css`\n- Demo service records: `data/services.ts`\n- Readiness logic: `lib/readiness.ts`\n- API endpoints: `app/api/`\n\n## API routes\n- GET `/api/services` or `/api/services?q=income`\n- GET `/api/services/income-certificate`\n- POST `/api/readiness` JSON: `{\"serviceId\":\"income-certificate\",\"checkedDocumentIds\":[\"identity\",\"address\",\"income\",\"photo\"],\"appointmentConfirmed\":false}`\n\n## Limitations\nThis is a demo, not an official government information source. Data is illustrative, no authentication or real appointment booking is implemented, and the data is not stored in a persistent database. `READY` means only that the demo rules passed. Verify all real-world details with official authorities.\n
